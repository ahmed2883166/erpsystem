# إدارة ربط الأدوار المحاسبية

من شاشة دليل الحسابات، يمكن لمدير الشركة أو المحاسب تعديل الحساب المرتبط بكل دور محاسبي.

## السلوك
- تعرض الشاشة جميع الأدوار المعروفة، مع الحساب الحالي أو حالة «غير مربوط».
- اختيار الحساب يتم من الحسابات التفصيلية النشطة والقابلة للترحيل داخل الشركة نفسها.
- حفظ الدور الموجود ينفذ تحديثًا للحساب المرتبط فقط.
- حفظ دور غير مربوط ينشئ الربط الأول.
- لا يمكن نقل الربط إلى شركة أخرى أو تغيير هوية الدور من خلال التعديل.
- يمنع الخادم ربط حساب تجميعي أو غير نشط أو غير قابل للترحيل أو تابع لشركة أخرى.
- لا تُعدّل أرقام الحسابات أو القيود السابقة عند تغيير الربط؛ الترحيلات المستقبلية تستخدم الدور والحساب الحاليين وفق منطقها.

## مراجعة محاسبية مهمة
قبل تغيير دور مستخدم في الترحيل الآلي، راجع أثره على المستندات الجديدة والتقارير. لا يقوم النظام بإعادة ترحيل القيود السابقة عند تغيير الربط.
