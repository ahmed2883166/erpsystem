# استيراد دليل الحسابات من Excel

## الاستخدام
1. افتح الشركة ثم دليل الحسابات.
2. اضغط «تحميل نموذج Excel» واستخدم ورقة «دليل الحسابات» أو جهّز ملفك بنفس الأعمدة.
3. ارفع ملف `.xlsx` واضغط «معاينة وفحص الملف».
4. راجع الحسابات الجديدة، والحسابات المطابقة التي ستُتخطى، وأي تعارضات أو تحذيرات أسماء.
5. لا يتاح زر الاعتماد إلا إذا انتهى الفحص دون أخطاء مانعة. اعتماد الاستيراد متاح لمدير الشركة فقط.

## الأعمدة
| العمود | مطلوب؟ | الوصف |
|---|---|---|
| كود الحساب | نعم | نص حتى 40 حرفًا. استخدم تنسيق Text للحفاظ على الأصفار في بداية الكود. |
| اسم الحساب | نعم | الاسم العربي حتى 180 حرفًا. |
| كود الأب | لا | اتركه فارغًا للحساب الرئيسي؛ وإلا يجب أن يشير إلى حساب مجموعة موجود في الملف أو الشركة. |
| طبيعة الحساب | نعم | أصول، التزامات، حقوق الملكية، إيرادات، مصروفات؛ أو القيم الإنجليزية المقابلة. |
| التصنيف | نعم | مجموعة أو تفصيلي. المجموعات لا تقبل الترحيل المباشر. |

## قواعد الحماية
- الحد الأقصى 5 ميجابايت و5,000 حساب و50 عمودًا.
- الكود المكرر داخل الملف، الحساب الأب المفقود، الأب غير التجميعي، التسلسل الدائري، أو اختلاف حساب موجود بنفس الكود تمنع الاعتماد.
- الحساب الموجود بنفس الكود والاسم والأب والطبيعة والتصنيف يُتخطى باعتباره مطابقًا.
- الاسم المتشابه بكود آخر يظهر كتحذير فقط؛ لا يحدث دمج تلقائي.
- الاستيراد إضافة فقط: لا يحذف أو يعيد تسمية أو ينقل حسابًا موجودًا، ولا يغير الأدوار المحاسبية أو القيود.
- المعاينة لا تحفظ أي بيانات. الاعتماد يعيد الفحص ثم ينشئ الحسابات الجديدة داخل معاملة قاعدة بيانات واحدة؛ أي خطأ أثناء الحفظ يلغي كامل العملية.
- بعد الاستيراد، راجع ربط أدوار الحسابات (النقدية، البنوك، الضريبة، التأمينات، الإيرادات، التكلفة) يدويًا قبل تشغيل الترحيل الآلي.

## الحدود الحالية
المدعوم حاليًا هو Excel بصيغة `.xlsx`. ملفات `.xls` وCSV غير مدعومة في هذه الشاشة. لا يتم استنتاج الدور المحاسبي من اسم الحساب، ولا يتم اعتماد ضريبة أو تأمينات أو حسابات رقابية تلقائيًا من تشابه الأسماء.
