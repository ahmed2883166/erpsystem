# الشريحة 20 — اختبار التراجع الذري لتهيئة المخططات على PostgreSQL

## النطاق
- توسيع اختبارات تهيئة مخططات العملات والبنوك والأصول الثابتة.
- حقن فشل متعمد بعد إنشاء جدول جزئي داخل schema مؤقت معزول.
- التأكد من أن initializer ينفذ rollback ولا يترك أي DDL جزئي بعد الفشل.
- التحقق من كل وحدة بشكل مستقل مع استعادة factory الأصلية وحذف schema الاختبار فقط.

## حدود السلامة
- الاختبارات مشروطة بوجود `NEXUS_TEST_POSTGRES_DSN`.
- لا تستخدم قاعدة تشغيل التطبيق ولا قاعدة بيانات شركة.
- لا تعدل أو تحذف أي بيانات خارج schema المؤقت الفريد للاختبار.
- لا تفتح PostgreSQL كقاعدة تشغيل للتطبيق.

## بوابة القبول
لا تُغلق الشريحة إلا بعد نجاح اختبارات PostgreSQL الفعلية على HEAD النهائي، واختبارات NEXUS وPython checks، مع بقاء SQLite قاعدة التشغيل الافتراضية.
