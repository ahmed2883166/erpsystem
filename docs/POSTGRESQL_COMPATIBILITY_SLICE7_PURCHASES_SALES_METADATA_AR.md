# شريحة توافق PostgreSQL 7 — بيانات المشتريات والمبيعات الوصفية

## النطاق
- أضيفت دالتا `_table_exists` و`_columns` في وحدتي المشتريات والمبيعات كواجهتين رفيعتين فوق `db_compat`.
- استُبدلت استعلامات `sqlite_master` الخاصة بوجود الجداول وعبارات `PRAGMA table_info` في هاتين الوحدتين بواجهات metadata المشتركة.
- بقي فحص فهارس SQLite في شاشة سلامة المشتريات كما هو؛ لم يتم الادعاء بأنه متوافق مع PostgreSQL.

## ما لم يتغير
- اتصال التطبيق في `db()` ما زال يستخدم `connect_database(DB_PATH)`، أي SQLite.
- لم تتغير أوامر SQL التشغيلية أو معاملات البيع والشراء أو GRNI أو المخزون أو الضرائب أو القيود أو الصلاحيات.
- لم يتم تحويل `executescript` أو `BEGIN IMMEDIATE` أو `lastrowid` أو إنشاء/ترقية المخطط إلى PostgreSQL.
- لذلك هذه الشريحة تهيئة محدودة لقراءة metadata وليست إعلانًا بأن الوحدتين جاهزتان للتشغيل على PostgreSQL.

## الاختبارات
- اختبار SQLite يستخدم قاعدة :memory:.
- اختبار PostgreSQL اختياري عبر `NEXUS_TEST_POSTGRES_DSN`، وينشئ جدولًا داخل schema مؤقتة ثم يتراجع عن المعاملة ويغلق الاتصال.
- لا يلمس الاختبار قاعدة بيانات الشركة ولا يغير بياناتها.
