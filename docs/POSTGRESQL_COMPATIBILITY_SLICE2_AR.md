# طبقة تنفيذ SQL — الشريحة الثانية

الحالة: محول اختياري ومحدود لعلامات معاملات SQL، وليس محرك تحويل SQL كاملًا.

## الإضافة

- `db_sql.py` يحتوي:
  - `qmark_to_format(sql)`: يحول علامة المعاملة `?` إلى `%s` في المواضع غير المحمية فقط.
  - `execute_compat(connection, sql, params)`: ينفذ SQL بعلامات `?` على SQLite كما هو، ويحوّلها عند استخدام psycopg 3.
- `tests/test_db_sql.py` يغطي:
  - علامات المعاملات داخل وخارج النصوص والـ identifiers.
  - تعليقات السطر والتعليقات متعددة الأسطر المتداخلة.
  - PostgreSQL dollar-quoted strings.
  - تنفيذ SQLite، واختبار PostgreSQL تكاملي اختياري مع قيمة NUMERIC دقيقة.

## قيود مهمة

1. هذا المحول لا يترجم SQL الخاص بـ SQLite إلى PostgreSQL.
2. لا تستخدمه مع تعبيرات PostgreSQL التي تعتمد على عامل JSON `?`؛ لأنه لا يستطيع التمييز بين عامل JSON وعلامة المعاملة في SQL غير المقتبس.
3. لا يغير حدود المعاملات ولا ينفذ commit أو rollback.
4. لا يعالج `INSERT OR IGNORE` أو `REPLACE` أو `lastrowid` أو `executescript` أو الدوال المخصصة.
5. لم يتم استبدال أي استدعاء في وحدات النظام الحالية؛ الاستخدام ما زال اختياريًا ومعزولًا.

## شروط الانتقال

لا نستخدم هذا المحول داخل وحدة محاسبية قبل اختبار استعلاماتها كاملة على المحركين، ومراجعة الاستعلامات التي تحتوي معاملات نصية أو عوامل خاصة، ثم مقارنة نتائج القراءة والكتابة والأرصدة.
