# نموذج أولي لمنسّق انتظار الكتابة في SQLite

## النطاق

أُضيف `sqlite_write_gate.py` كنموذج أولي اختياري لمنسّق FIFO بين خيوط التنفيذ داخل **عملية Python واحدة**. لا يستبدل أقفال SQLite ولا يغير سلوك قاعدة البيانات بمفرده.

## ما الذي يختبره؟

- دخول الكتّاب حسب ترتيب وصولهم إلى طابور المنسّق.
- مهلة انتظار اختيارية وإزالة المنتظر المنتهي وقته دون تعطيل بقية الطابور.
- تحرير المنسّق عند خروج العملية باستثناء.
- عدّ المنتظرين لأغراض التشخيص.

## ما الذي لا يفعله؟

- غير مربوط بـ `connect_database` أو أي مسار ترحيل في التطبيق.
- لا ينسق بين أكثر من عملية WSGI أو خادم وأكثر من جهاز يتصل مباشرة بملف SQLite.
- لا يغير `BEGIN IMMEDIATE` أو `commit` أو `rollback` ولا يضمن تحسين قياس 30 جهازًا.
- لا يُعد موافقة على نشره في الإنتاج.

## بوابة الدمج قبل أي ربط بالتطبيق

1. نجاح اختبارات FIFO والمهلة والتحرير بعد الاستثناء.
2. تجربة تحميل مقارنة على نفس قاعدة الاختبار المؤقتة وبنفس عدد الكتّاب والقرّاء.
3. التحقق من عدم فقد أو تكرار القيود، وتوازن المدين والدائن، ونجاح `PRAGMA integrity_check`.
4. قياس أثره مع نمط تشغيل Waitress الفعلي، بما في ذلك عدد العمليات.
5. إبقاء حدود المعاملات المحاسبية كما هي، وعدم دمج أي تعديل على المسارات قبل نتائج المقارنة.

كل الاختبارات تستخدم بيانات مؤقتة؛ لا يتم فتح أو تعديل قاعدة بيانات الشركة.
