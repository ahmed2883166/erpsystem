# شريحة توافق PostgreSQL رقم 13 — بيانات وصفية لشجرة الحسابات

## ما تم
- استبدال قراءة PRAGMA table_info(accounts) في chart_templates.py بمساعد table_columns المشترك.
- إضافة دالة _account_columns لتجميع قراءة أعمدة الحسابات في نقطة واحدة.
- إضافة اختبار SQLite واختبار PostgreSQL اختياري داخل schema مؤقتة ومعاملة يتم التراجع عنها.

## حدود التغيير
- التغيير خاص باكتشاف أسماء أعمدة accounts فقط.
- لم يتم تعديل أرقام الحسابات أو أنواعها أو علاقات الأب والابن أو أدوار الحسابات.
- لم يتم تعديل ترحيل القيود أو الأرصدة أو أرصدة السنوات السابقة.
- ما زالت أوامر تحديث البيانات بعلامات ? وبقية مسارات الإدخال وlastrowid بحاجة إلى توافق مستقل.
- لا يعني هذا أن chart_templates.py أو شجرة الحسابات جاهزة بالكامل لـ PostgreSQL.

## حماية البيانات
لم يتم الاتصال بقاعدة بيانات الشركة أو تعديل أرصدتها. اختبارات PostgreSQL تستخدم schema مؤقتة وتُلغى معاملتها.
