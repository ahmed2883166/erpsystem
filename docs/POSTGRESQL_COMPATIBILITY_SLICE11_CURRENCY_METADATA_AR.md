# شريحة توافق PostgreSQL رقم 11 — بيانات وصفية لمركز العملات

## النطاق
- استبدال فحص وجود جدول سجل المراجعة الاختياري في `currency_center.py` باستدعاء `table_exists` المحايد لقواعد البيانات.
- إضافة اختبار SQLite واختبار PostgreSQL اختياري داخل schema مؤقتة ومعاملة يتم التراجع عنها.

## ما لم يتغير
- لم تتغير أسعار الصرف أو تسوية الذمم أو فروق العملة المحققة أو إعادة التقييم أو القيود المحاسبية.
- لم تتغير الصلاحيات أو سجل المراجعة أو أي بيانات معاملات.
- إنشاء جداول مركز العملات ما زال يستخدم DDL خاصًا بـ SQLite عبر `executescript`.
- استعلامات القراءة والكتابة ما زالت تستخدم علامات `?` وسلوك SQLite، و`_db()` ما زال يفتح اتصال SQLite.
- معاملات `BEGIN IMMEDIATE` ومعالجة أخطاء SQLite لم تتغير.

## حدود الاعتماد
هذه شريحة metadata فقط، ولا تعني أن مركز العملات جاهز للتشغيل على PostgreSQL. اختبار PostgreSQL يتحقق من فحص وجود جدول سجل المراجعة فقط. لم يتم تغيير قاعدة بيانات التشغيل أو لمس بيانات الشركات.
