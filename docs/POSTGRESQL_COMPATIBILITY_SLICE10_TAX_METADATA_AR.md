# شريحة توافق PostgreSQL رقم 10 — بيانات وصفية لمركز الضرائب

## النطاق
- توحيد فحص وجود الجداول والأعمدة في tax_center.py عبر db_compat.
- استبدال فحوص PRAGMA table_info واكتشاف الجداول عبر sqlite_master في بيانات الأطراف والإشعارات الدائنة ومطابقة الأستاذ وسجل مراجعة المستندات.
- إضافة اختبارات SQLite واختبار PostgreSQL اختياري داخل schema مؤقتة ومعاملة يتم التراجع عنها.

## ما لم يتغير
- لم تتغير معادلات ضريبة المخرجات أو المدخلات أو نسب الخصم أو تصنيف المستندات أو المطابقة المحاسبية.
- لم تتغير الصلاحيات أو سجل المراجعة أو القيود أو المستندات المرحلة.
- تهيئة سجل المراجعة وإضافات الأعمدة ما زالت تستخدم DDL خاصًا بـ SQLite.
- استعلامات التقرير والحفظ ما زالت تستخدم SQL بعلامات ? وسلوك SQLite؛ اتصال الوحدة ما زال SQLite.

## حدود الاعتماد
هذه شريحة metadata فقط، ولا تعني أن مركز الضرائب جاهز للتشغيل على PostgreSQL. اختبار PostgreSQL يتحقق من غلافي فحص الجداول والأعمدة فقط. لم يتم تغيير قاعدة بيانات التشغيل أو لمس بيانات الشركات.
