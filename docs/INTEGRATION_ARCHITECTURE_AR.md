# ترابط وحدات NEXUS ERP — التصميم والتنفيذ الحالي

## القاعدة الأساسية
كل الوحدات تستخدم قاعدة SQLite واحدة `data/nexus.db`. لا تنشئ كل وحدة دفتر أستاذ أو قاعدة مالية مستقلة. المستند التشغيلي هو مصدر الحقيقة، ويُرحّل أثره المحاسبي مرة واحدة إلى دفتر الأستاذ.

## محرك الترحيل المشترك
الملف `accounting_core.py` هو نقطة الترحيل المشتركة:
- يتحقق من وجود الحساب وأنه تفصيلي ونشط.
- يتحقق من أن كل سطر مدين أو دائن فقط.
- يرفض القيد غير المتوازن.
- يمنع إعادة إنشاء قيد منشور بنفس المرجع.
- يكتب رأس القيد وسطور اليومية داخل معاملة قاعدة البيانات التي بدأتها الوحدة المستدعية.

الوحدات المرتبطة حاليًا بالمحرك:
- القيود اليدوية من شاشة اليومية.
- قيود الصرف والتالف في المخزون.
- قيود الاستلام وGRNI وفواتير الموردين وسداد الموردين.

## دورة المشتريات
1. تعريف المورد.
2. أمر شراء (حاليًا رأس أمر وسطر صنف واحد في شاشة الإنشاء).
3. استلام البضاعة: حركة مخزون + طبقة تقييم + Dr مخزون / Cr GRNI.
4. فاتورة المورد: Dr GRNI / Cr المورد، مع ضريبة مدخلات عند تفعيل حسابها.
5. السداد: Dr المورد / Cr الصندوق أو البنك، وتوزيع الدفعة على أقدم الفواتير المفتوحة.

حدود مهمة: استلام الكميات الجزئية وربطها بأمر الشراء لم يكتمل بعد. فاتورة المورد المباشرة دون إذن استلام لا تزيد كمية المخزون. لا توجد مرتجعات مشتريات أو إشعارات دائنة أو دفعات مقدمة حتى الآن.

## مركز المطابقة
المسار `/reports/reconciliation` يعرض:
- إجمالي المدين والدائن للقيود المرحلة.
- القيود غير المتوازنة إن وجدت.
- قيمة طبقات المخزون مقارنة برصيد حساب المخزون.
- قيمة GRNI غير المطابقة مبدئيًا.
- صافي الفواتير المفتوحة للموردين.

هذا تقرير رقابي أولي، وليس بديلًا عن المطابقة التفصيلية حسب الصنف والمورد والمستند.

## الترابط المستهدف للدورات التالية
- المبيعات: أمر بيع ← تسليم ← فاتورة ← عميل/ضريبة/إيراد + تكلفة مبيعات/مخزون ← تحصيل.
- المشتريات: استلام/فاتورة ← مورد/ضريبة/مخزون أو مصروف ← سداد.
- الخزينة: سند قبض/صرف ← حساب عميل أو مورد أو مصروف/إيراد ← بنك/صندوق.
- الأصول: إضافة أصل ← سجل أصل ← إهلاك دوري ← دفتر الأستاذ.
- الرواتب: مسير معتمد ← مستحقات موظفين وتأمينات وضرائب ← السداد.
- التقارير: دفتر الأستاذ وميزان المراجعة والقوائم تستمد من قيود اليومية المرحلة، لا من جداول تشغيل منفصلة.

## ما لا يزال مطلوبًا
إكمال دورة المبيعات والخزينة والأصول والرواتب، وربط أوامر الشراء والاستلام الجزئي، وإضافة المرتجعات والعكس المحاسبي، ومطابقة أرصدة العملاء والموردين، ومراجعة تقييم المخزون، واختبارات تكامل كاملة. كما يلزم تأمين النظام واختبار النسخ الاحتياطي والصلاحيات وقفل الفترات وتجهيز مثبت Windows. لا يستخدم النظام ببيانات فعلية قبل اكتمال ذلك ومراجعته.
