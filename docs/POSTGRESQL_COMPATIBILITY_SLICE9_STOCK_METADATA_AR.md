# شريحة توافق PostgreSQL رقم 9 — بيانات وصفية للمخزون

## النطاق
- إضافة غلافي `_table_exists` و`_columns` في `stock.py` بالاعتماد على `db_compat`.
- استبدال قراءات `PRAGMA table_info` واستعلامات `sqlite_master` الخاصة باكتشاف الجداول والأعمدة في مسارات التهيئة والتقارير والتحقق من الإعدادات.
- إضافة اختبارات SQLite واختبار PostgreSQL اختياري داخل schema مؤقتة ومعاملة يتم التراجع عنها.

## ما لم يتغير
- لا تغيير في حركات المخزون أو التقييم أو FIFO/المتوسط أو منع المخزون السالب أو القيود المحاسبية.
- لا تغيير في الترحيل أو الصلاحيات أو الأرصدة أو بيانات الشركة.
- لم يتم تحويل SQL التشغيلي أو `lastrowid` أو `BEGIN IMMEDIATE` أو `INSERT OR IGNORE` أو `executescript`.
- `get_db()` ما زال يفتح SQLite؛ لذلك وحدة المخزون ليست جاهزة للتشغيل على PostgreSQL.

## حدود الاعتماد
هذه شريحة metadata فقط. الانتقال الفعلي يحتاج معالجة مستقلة للمعاملات، وإرجاع المعرفات، وعمليات الإدخال المتوافقة، وأنواع البيانات، واختبارات تكامل لكل مسارات المخزون، مع عدم استخدام قاعدة بيانات الشركة في الاختبارات.
