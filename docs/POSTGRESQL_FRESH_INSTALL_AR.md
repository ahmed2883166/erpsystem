# تهيئة تثبيت جديد على PostgreSQL

هذه الخطوات تنشئ مخطط شركة جديدًا من الصفر. لا تقرأ قاعدة SQLite القديمة ولا تنقل أي بيانات منها، ولا تحذف أي مخطط أو جدول موجود.

## 1) توليد خط الأساس

من جذر المشروع:

```powershell
python scripts/build_postgres_baseline.py --output-dir build/postgres
```

ينتج:
- `build/postgres/nexus_full_schema.sql`
- `build/postgres/nexus_full_schema_review.json`

راجع ملف المراجعة قبل التثبيت، خصوصًا أنواع الحقول الرقمية المرشحة. لا تغيّر أنواع الحقول تلقائيًا اعتمادًا على أسمائها فقط.

## 2) إنشاء قاعدة/مخطط PostgreSQL فارغ

أنشئ قاعدة PostgreSQL مخصصة للشركة ومستخدمًا محدود الصلاحيات عليها. يجب أن يستطيع المستخدم إنشاء schema والجداول والفهارس والقيود والـtriggers داخل قاعدة الشركة. لا تستخدم schema `public` لهذا التثبيت.

## 3) تثبيت المخطط وتهيئة بيانات البداية

مثال PowerShell (عدّل DSN ومسارات المجلدات حسب بيئتك):

```powershell
$env:NEXUS_POSTGRES_DSN = "host=127.0.0.1 port=5432 dbname=nexus_erp user=nexus_app password=CHANGE_ME"
python scripts/initialize_postgres_fresh_install.py `
  --ddl build/postgres/nexus_full_schema.sql `
  --schema nexus `
  --data-dir "$env:LOCALAPPDATA\NEXUS ERP\data" `
  --backup-dir "$env:LOCALAPPDATA\NEXUS ERP\Backups"
```

المهيئ:
- يثبت خط الأساس في schema فارغ فقط.
- يسجل بصمة SHA-256 للـDDL، ويسمح بإعادة تشغيل التهيئة إذا كانت البصمة مطابقة.
- يرفض schema غير فارغ لا يحتوي سجل تثبيت مطابقًا، ويرفض اختلاف بصمة خط الأساس.
- يشغل مهيئات NEXUS الفعلية لإنشاء الإعدادات الافتراضية وشجرة الحسابات والمستخدم الإداري والجداول الفرعية.
- يتحقق من وجود جداول الحسابات والعملاء والموردين والمبيعات والمشتريات والمخزون والبنوك والأصول والموارد البشرية والمرتبات.
- يحفظ كلمة مرور المدير المؤقتة في الملف المشار إليه في نتيجة التشغيل؛ يجب تغييرها عند أول دخول.

## حد مهم — لا يعني فتح تشغيل PostgreSQL

نجاح هذا الأمر يعني أن مخطط PostgreSQL وتهيئة الشركة الأولية تم إنشاؤهما والتحقق منهما فقط. لا يفتح بوابة تشغيل التطبيق على PostgreSQL. تظل `database_backend.py` رافضة لتشغيل PostgreSQL العادي حتى اجتياز اختبارات العمليات الفعلية لكل الوحدات (بما فيها المبيعات والمشتريات والبنوك والأصول والمرتبات والتقارير والنسخ الاحتياطي والاستعادة).

لا تضبط `NEXUS_DB_BACKEND=postgresql` لتشغيل المستخدمين قبل اعتماد بوابة التوافق. لا تستخدم هذا المهيئ على قاعدة شركة تحتوي بيانات أو على schema مستخدم بالفعل.
